ThriveX 是一套自托管的个人博客系统，由三个可以独立部署的单元组成：

- **ThriveX-Server** — Spring Boot 3.5 后端，负责内容、用户、评论、文件与统计
- **ThriveX-Admin** — Vite + React 19 管理端，用来写文章、管分类、配主题
- **ThriveX-Blog** — Next.js 16 前台，就是你正在看的这个站点

后端提供 REST 接口，Admin 和 Blog 都通过 `src/lib` 里的封装调用它，Blog 额外直连服务器内部地址做服务端渲染缓存。

## 这个知识库是什么

这里的每一页都是仓库里的一个 `.md` 文件，存放在 `src/content/docs/` 下，随代码一起提交。它和文章共用同一套 Markdown 渲染管线，所以你在文章里能用的语法、公式、代码高亮、自定义组件，这里都能用。

## 怎么翻页

左侧是全部目录，按分组排列；右侧是当前页的标题索引，会跟随滚动高亮。读到底部有上一页和下一页，也可以用 `Ctrl + K` 打开全局命令面板直接跳转。

## 怎么挂到导航上

站点导航来自数据库的分类表，不需要改代码。在管理端新建一条分类，类型选 `page`、链接填 `/docs`，导航栏就会出现「知识库」入口，并且在本窗口打开。

> 文档随代码演进。如果某页和实际行为对不上，那是文档过时了，不是功能变了。
